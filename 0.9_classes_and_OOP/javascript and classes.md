## Four Pillars
- Abstraction // hide unnecessary details and show only the essential features of something. We often use fetch as part of abstraction. Fetch hides all the internal details.

- Encapsulation // bundling data (variables) and methods (functions) together, and restricting direct access to some of that data. It works as a wrapper like keeping important data protected inside an object, and only allow controlled access to it.

- Inheritance // where one object (or class) gets properties and methods from another, so we can reuse code instead of rewriting it.

- Polymorphism // means “many forms”—it’s when the same method or function behaves differently depending on the object or context.
